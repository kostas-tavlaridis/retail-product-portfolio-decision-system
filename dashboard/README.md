# Power BI dashboard

Start with the [dashboard guide](POWER_BI_DASHBOARD.md) for the four-page walkthrough and screenshots. [Download the PBIX](Product_Portfolio_Dashboard.pbix) to open the interactive report in Power BI Desktop.

The PBIX embeds a snapshot of the [governance workbook](../python/reports/governance_output.xlsx). Regenerating that workbook does not automatically update the saved report; the embedded copy must be replaced and the PBIX checked again.
